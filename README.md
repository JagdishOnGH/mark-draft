## 📖 Overview  

**MarkDraft AI** is a modern, **React‑based** web app that lets you write, preview, and enhance Markdown documents with AI‑powered suggestions. It features a **collapsible sidebar**, **synchronised scrolling**, and a sleek dark‑mode UI that feels premium out‑of‑the‑box.

> **Keywords:** markdown editor, AI writing assistant, live preview, collapsible sidebar, sync scroll, React, Vite, Gemini, SEO‑friendly, open‑source  

## ✨ Key Features  

| Feature | Description |
|---|---|
| **Live Markdown Preview** | Real‑time rendering with syntax highlighting, tables, images, and GitHub‑flavoured markdown. |
| **AI‑Assisted Writing** | Powered by Google Gemini (`@google/genai`) to suggest completions, re‑phrasing, and content ideas. |
| **Collapsible Sidebar** | Desktop‑friendly sidebar that can be hidden to maximise writing space. |
| **Bidirectional Sync Scroll** | Accurate line‑based scrolling sync between editor and preview panes. |
| **Dark / Light Mode** | Automatic theme detection with smooth transitions. |
| **Responsive Design** | Mobile‑first layout that works on phones, tablets, and desktops. |
| **Extensible Architecture** | Component‑based codebase ready for custom plugins or additional AI models. |

## 🚀 Getting Started  

### Prerequisites  

- **Node ≥ 20** (LTS)  
- **npm ≥ 10**  

### Installation  

```bash
# Clone the repo
git clone https://github.com/JagdishOnGH/mark-draft.git
cd mark-draft

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open <http://localhost:5173> in your browser. The app will hot‑reload as you edit source files.

### Build for Production  

```bash
npm run build   # Vite bundles the app
npm run preview # Preview the production build locally
```

## 📚 Usage  

1. **Write** Markdown in the left pane.  
2. **Preview** updates instantly on the right.  
3. Click the **hamburger icon** (top‑left) to toggle the sidebar.  
4. Use the **link/unlink icon** in the top bar to enable/disable scroll sync.  
5. Press **Ctrl + Space** (or click the AI button) to get AI suggestions.
